## 三、升级机制

- 每升 1 级获得 **10 点潜力**：其中 5 点由系统自动平均分配到五项属性（每项 +1），
  剩余 **5 点**由玩家自由分配。
- 30~39 级有 1 次免费洗点机会（门派传送人处）。
- 渡劫后可获得一次免费全洗点机会（无时间限制）。
- 洗点下限：`种族初始属性 + 当前等级`（即升级自动分配的部分不可洗）。

## 四、战斗面板属性

> **本节数值已用第一节的「0 级未加点面板表」反推校验过**（属性点已知、面板值已知，可直接解系数）。
> 校验中发现并修正了两处早期错误，见下方 ⚠ 标注。

### 1. 命中（物理命中）

| 种族 | 公式 |
|---|---|
| 人族 | 力量×2 + 30 |
| 魔族 | 力量×2.3 + 30 |
| 仙族 | 力量×1.7 + 30 |

⚠ **修正**：早期版本写魔族截距为 27，错误。魔族 0 级力量 11，`11×2.3+27 = 52.3`，
与面板表的 **55** 对不上；改用截距 30 后 `11×2.3+30 = 55.3 → 55` ✓。
三族用统一截距 30 时，人（`10×2+30=50`）、仙（`11×1.7+30=48.7→48`）也**全部**吻合面板表。

来源：力量、装备命中、灵饰、符石（金光符石 +4 命中）。命中不影响法术伤害。

### 2. 伤害（物理攻击力）

| 种族 | 公式 |
|---|---|
| 人族 | 力量×0.7 + 34 |
| 魔族 | 力量×0.8 + 34 |
| 仙族 | 力量×0.6 + 40 |

> **系数分歧（官方未公布，两套并存，差约 6%）**
>
> | | 人 | 魔 | 仙 | 出处 |
> |---|---|---|---|---|
> | **A 套（本文档采用）** | 0.7 | 0.8 | 0.6 | GameRes 数值设计思想、TapTap、本节面板公式 |
> | B 套 | 0.66 | 0.76 | 0.56 | 3DM 2025 换算表、本文档第二节成长表 |
>
> **采用 A 套的理由**：截距干净（34/34/40），且能精确复现人族 0 级面板伤害
> （`10×0.7+34 = 41` ✓）；B 套要凑出 34.4 这种截距。玩家实测得到的 0.67/0.77/0.57
> 带着一个恒定的 −0.03 偏移，更像是面板取整造成的拟合误差。
> **第二节成长表里的 0.66/0.76/0.56 保留原样作为 B 套的记录，实现时以本节 A 套为准。**

来源：力量、武器伤害、太阳石、灵饰伤害、符石、临时符。
**关键换算**：对法系门派，约 **4 点伤害 → 1 点法术伤害**（武器伤害、太阳石、龙附临时都按此转换）。

### 3. 防御（物理防御）

| 种族 | 公式 |
|---|---|
| 人族 | 耐力×1.5 |
| 魔族 | 耐力×1.4 |
| 仙族 | 耐力×1.6 |

⚠ **修正**：早期版本本节写魔族 `耐力×1.3`，与**同文档第二节成长表**的「魔族 1 耐力 = 1.4 防御」自相矛盾。
魔族 0 级耐力 8、面板防御 11：`8×1.3 = 10.4 → 10` ✗；`8×1.4 = 11.2 → 11` ✓。
**1.4 正确**（3DM 2025 换算表亦为 1.4）。

来源：耐力、装备防御、月亮石、灵饰防御、符石（碧玉符石 +3 防御）。

### 4. 速度（出手顺序）

| 种族 | 公式 |
|---|---|
| 三族通用 | 体质×0.1 + 力量×0.1 + 耐力×0.1 + 敏捷×0.7 |

**注意**：魔力不加速度，敏捷是速度的主要来源。
额外加成：神速技能满级 +60 速度、黑宝石（鞋子）、符石（霞光符石 +1.5 速度）。

### 5. 法术伤害（法伤）

法伤为后期版本（灵饰系统后）独立的面板项，**原版只有"灵力"综合属性**。

- **灵力公式（三族通用）**：体质×0.3 + 魔力×0.7 + 力量×0.4 + 耐力×0.2（敏捷不加灵力）
- **独立法伤来源**：魔力、灵饰法伤、符石（火符石 / 星辰符石 / 流风符石 +1~2 法伤）、
  武器伤害按 4:1 转换、师门技能（二次函数曲线 `x²/a + x·b + c`）。
- **法伤 vs 法防差值**会进入法术伤害结算公式（如超级三昧真火公式中含 `+法伤法防差`）。

### 6. 法术防御（法防）

同样为后期独立面板项。

- **来源**：灵饰法防、符石（电符石 +1 法防、雪月符石 +2 法防、子蚀符石 +2 法防、百冥符石 +2 法防）。
- 灵力本身同时影响法伤与法防（综合属性），独立法防面板主要靠灵饰和符石堆叠。

## 五、资源面板属性

### 1. 气血（HP）

| 种族 | 公式 |
|---|---|
| 人族 | 体质×5 + 100 |
| 魔族 | 体质×6 + 100 |
| 仙族 | 体质×4.5 + 100 |

**加成来源**：
- **强身术**（满级 140）：按百分比加成，**气血 × (1 + 140%) = 气血 × 2.4**
- **强壮**（满级 40）：固定值，约 **+1440 血**（15 × 40 × 2.4）
- 光芒石（+40 血 / 级）、灵饰气血、装备气血、临时符

### 2. 魔法（MP）

| 种族 | 公式 |
|---|---|
| 人族 | 魔力×3 + 80 |
| 魔族 | 魔力×2.5 + 80 |
| 仙族 | 魔力×3.5 + 80 |

**加成来源**：冥想技能（按百分比提升魔法上限）、神秘石（+15 蓝 / 级）、装备魔法。

### 3. 愤怒（特技资源）

- **上限**：150（基础无符上限 70，狮驼岭愤怒符可加到 80+）
- **战斗中受伤害获取**：

  | 单次伤害占气血比 | 获得愤怒 |
  |---|---|
  | 0–3%    | +1  |
  | 3–10%   | +3  |
  | 10–20%  | +10 |
  | 20–30%  | +15 |
  | 30–50%  | +25 |
  | 50–80%  | +40 |
  | 80–100% | +55 |

- **酒类道具**：珍露酒 = 品质×0.4 + 10；蛇胆酒 = 品质×1（降防御）
- **愤怒腰带特效**：特技消耗 -20%
- **死亡清零**；普陀治疗、地府尸腐毒为目标 +1 愤怒
- **注意**：主动技能消耗血量（如大唐横扫千军）不增加愤怒

### 4. 活力（生活技能资源）

- **用途**：烹饪、炼药、打造辅助等
- **上限提升**：养生之道技能（175 满级约 **1565**）
- **恢复**：在线每 5 分钟恢复一次
  - **恢复值 = 活力上限 × 1%（取整）+ 等级 × 2%（取整）+ 2**
  - 例：109 级、上限 860 → 每 5 分钟恢复 12 点

### 5. 体力（生活技能资源）

- **用途**：打造、炼金、裁缝、熔炼等力量类活动
- **上限提升**：健身术技能（175 满级约 **1565**）
- **恢复**：与活力同公式，每 5 分钟恢复一次

## 六、属性关系速记图

```
体质 → 气血(大) + 速度(0.1) + 灵力(0.3)
魔力 → 魔法(大) + 灵力(0.7)
力量 → 命中(大) + 伤害(大) + 速度(0.1) + 灵力(0.4)
耐力 → 防御(大) + 速度(0.1) + 灵力(0.2)
敏捷 → 速度(0.7) + 躲避(1)
```

**种族特点**：
- **魔族**：体、力强，耐弱
- **仙族**：魔、耐强，体、力弱（仙族物理面板最低，俗称"仙族 X 傻"，靠经脉补偿）
- **人族**：全属性均衡

## 七、物理伤害结算（参考）

- **基础公式**：伤害结果 = (伤害力 + 伤害力² / 3000 × 波动系数) × (1 + 伤害效果加成)
  - 伤害力 = 攻击方面板伤害 - 防御方面板防御
  - 波动系数：90% – 110% 随机
  - 伤害效果加成：修炼、阵法等百分比增幅
- **破防 / 不破防**：
  - 不破防：防御力 > 伤害力 × 90%，实际伤害 = 伤害力 × 10% × 伤害系数
  - 破防：防御力 < 伤害力 × 90%，实际伤害 = (伤害力 - 防御力) × 伤害系数
- **伤害系数**：PVP 默认 1.3，PVE 默认 1.2
